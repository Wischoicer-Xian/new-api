# 工作台系统 Key 的单独分组授权

环境变量 `WISCHOICER_SYSTEM_TOKEN_GROUP_GRANT` 默认不设置；未设置或内容无效时不会新增授权。必要时由生产运营配置一条 JSON：

```json
{"user_id":123,"token_id":456,"user_group":"既有用户分组","group":"目标工作台分组"}
```

仅当已验证的令牌是隐藏系统 Key，且用户 ID、令牌 ID、当前用户分组和令牌现有目标分组全部匹配时，才允许该令牌访问目标分组。该设置不改变账号或令牌的数据，不放开自动分组，不替代账号、令牌、额度、IP、模型限制、分组启用和计费规则。

从现行主分支构建；启动独立候选后，以目标系统 Key 验证真实模型列表，并验证其他令牌原有访问规则。切换入口前保留可用旧实例和回滚配置。需要撤销时，从部署配置移除该变量并平滑替换。不要将实际令牌内容写入配置、Git 或日志。
